# Nexus Mod covers

Seven original promotional illustrations generated with the built-in image_gen tool. These are cover artwork, not gameplay screenshots. Each PNG is exported at 1300 × 372 pixels, with proportional scaling and vertical cropping. The final generation prompts are in [prompts.json](prompts.json).

Upload each PNG as the corresponding Nexus cover. Each cover is stored in its Mod assets directory and displayed in its README. Covers remain excluded from installation packages by the existing package allowlists.

七张封面均为内置 image_gen 生成的原创宣传插画，不是实机截图。PNG 统一导出为 1300 × 372 像素，等比缩放并裁切上下边缘，可直接上传为对应 Mod 的 Nexus 封面。封面存放在对应 Mod 的 assets 目录中，并作为 README 首图展示；现有安装包白名单不包含封面。
