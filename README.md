### Getting started

**Choose your download:** use the individual Nexus pages or GitHub Releases above, or the [seven-Mod Nexus collection](https://www.nexusmods.com/games/oldmarketsimulator/collections/d8iufz) for Vortex. The collection pins the BepInEx editions; install BepInEx separately and follow its collection instructions.

These Mods are for **Old Market Simulator 2.1.6 on Windows**. Most use **BepInEx 5**; Material Cost also has a **MelonLoader 0.7.3** edition. Choose one loader, not both. Loaders are not included in the Mod downloads.

1. Close the game and back up your save and any old plugin.
2. Open the Mod's page above and follow its installation instructions.
3. For manual installation, download the Mod ZIP from Nexus **Files** or GitHub Release **Assets**. GitHub's **Source code** download is not an installable plugin.
4. Start the game and try the controls described in the Mod's guide.

**Using Stack All with friends? Everyone needs the same version.** Before removing it, follow its [save and removal instructions](stack-all-mod/README.md). Other Mods have their own multiplayer notes.

The seven versions linked above are stable releases. The maintainer confirmed acceptance of the seven-Mod set on September 19; Navigation 0.2.1's map and zoom fixes received local acceptance on September 20. Earlier multiplayer reports and the limits of those checks remain in the [validation record](releases/validation.md); stable status does not imply every scenario or Mod combination was tested. Keep a backup, especially before game updates or changing inventory Mods.

### 开始使用

**选择下载方式：** 从上表进入单个 Mod 的 Nexus 页面或 GitHub Release，也可以通过 [Nexus 七款合集](https://www.nexusmods.com/games/oldmarketsimulator/collections/d8iufz)使用 Vortex。合集固定使用 BepInEx 版本，请单独安装 BepInEx，并按合集页面的说明操作。

适用于 **Windows 版 Old Market Simulator 2.1.6**。多数 Mod 使用 **BepInEx 5**；Material Cost 还提供 **MelonLoader 0.7.3** 版本。加载器二选一，不要同时启用，Mod 下载包也不包含加载器。

1. 退出游戏，备份存档和已有的旧插件。
2. 打开上方对应 Mod 页面，按说明安装。
3. 手动安装时，从 Nexus 的 **Files** 或 GitHub Release 的 **Assets** 下载 Mod ZIP。GitHub 的 **Source code** 下载不是可安装插件。
4. 启动游戏，按使用说明试试功能。

**和朋友一起用 Stack All 时，所有人都需要相同版本。**卸载前请按它的[存档与卸载说明](stack-all-mod/README.md)整理库存。其他 Mod 的联机要求见各自页面。

上方链接的七个版本均为正式发布版。维护者于 9 月 19 日确认七款 Mod 的验收，Navigation 0.2.1 的地图和缩放修正于 9 月 20 日另获本地验收。此前联机报告和具体测试范围仍保留在[验证记录](releases/validation.md)中，正式版不代表已测试所有场景或 Mod 组合。请留好备份，尤其是在游戏更新或更换库存 Mod 前。
