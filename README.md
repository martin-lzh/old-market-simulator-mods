### Getting started

These Mods are for **Old Market Simulator 2.1.6 on Windows** and need a mod loader, installed separately: **BepInEx 5** for all of them, or **MelonLoader 0.7.3** for Profit Insights only. Use one loader, not both.

Download each Mod from its Nexus page or GitHub Release above, or install all seven at once through the [Nexus collection](https://www.nexusmods.com/games/oldmarketsimulator/collections/d8iufz) with Vortex (BepInEx editions).

1. Close the game and back up your save and any old plugin.
2. Open the Mod's page above and follow its installation instructions.
3. For manual installation, download the Mod ZIP from Nexus **Files** or GitHub Release **Assets**, not GitHub's **Source code**.
4. Start the game and try the controls described in the Mod's guide.

**Playing Better Stacking with friends? Everyone needs the same version.** Before removing it, follow its [save and removal steps](stack-all-mod/README.md#backups-and-removal). The other Mods only need to be installed by the players who want them.

Back up your save before game updates and before adding or removing inventory Mods.

### 开始使用

适用于 **Windows 版 Old Market Simulator 2.1.6**，需要先单独安装 Mod 加载器：全部 Mod 都支持 **BepInEx 5**，Profit Insights 另支持 **MelonLoader 0.7.3**。两个加载器只用一个。

可以从上表进入单个 Mod 的 Nexus 页面或 GitHub Release 下载，也可以用 Vortex 通过 [Nexus 合集](https://www.nexusmods.com/games/oldmarketsimulator/collections/d8iufz)一次装好七款（BepInEx 版本）。

1. 退出游戏，备份存档和已有的旧插件。
2. 打开上方对应 Mod 页面，按说明安装。
3. 手动安装时，从 Nexus 的 **Files** 或 GitHub Release 的 **Assets** 下载 Mod ZIP，不要下载 GitHub 的 **Source code**。
4. 启动游戏，按使用说明试试功能。

**和朋友一起用 Better Stacking 时，所有人都需要相同版本。**卸载前请按它的[备份与卸载步骤](stack-all-mod/README.md#备份与卸载)整理库存。其他 Mod 只需想用的玩家自己安装。

游戏更新前、增删库存类 Mod 前，请先备份存档。
