# 行为准则 / Code of Conduct

[中文](#中文) | [English](#english)

## 中文

本准则适用于项目的 Issues、Pull Requests 和其他项目协作讨论。

### 参与讨论

尊重不同经验、语言和观点。反馈针对代码、行为和证据，清楚说明问题并给对方修正机会；避免人身攻击、歧视、骚扰、威胁和持续纠缠。不发布他人隐私、未经允许的私人通信、恶意链接或垃圾广告。

发现风险时遵守安全报告流程，不以公开漏洞细节或敏感数据施压。贡献者可以不同意技术判断，也可以停止参与讨论。

### 处理与报告

维护者可要求修改内容、关闭偏离主题的讨论，并根据严重程度或重复情况限制参与；处理时尽量说明依据。被处理者可以请求维护者复核并提供相关背景。

目前未设置专用私密举报渠道。可使用平台针对具体内容的举报功能；如果维护者公布私密联系渠道，也可直接报告。不要为举报而公开他人个人信息；普通技术分歧可在原讨论中请求维护者协调。此文不承诺固定响应时间。

## English

This code applies to project Issues, Pull Requests, and other project collaboration discussions.

### Participation

Respect different experience levels, languages, and views. Focus feedback on code, behavior, and evidence; explain the problem and give others an opportunity to address it. Do not engage in personal attacks, discrimination, harassment, threats, or persistent unwanted contact. Do not post private information, private correspondence without permission, malicious links, or spam.

Follow the security reporting process when you discover a risk. Do not use public disclosure of vulnerability details or sensitive information as pressure. Contributors may disagree with technical judgments or stop participating.

### Enforcement and reporting

Maintainers may request edits, close off-topic discussions, and restrict participation based on severity or repeated behavior, explaining their reasons where possible. Affected participants may request review and provide relevant context.

There is currently no dedicated private reporting channel. Use the platform's reporting tools for specific content, or a private contact channel if maintainers publish one. Do not disclose personal information to make a report. For ordinary technical disagreements, request maintainer mediation in the existing discussion. No fixed response time is promised.
