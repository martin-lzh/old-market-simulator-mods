# Collection artwork / 合集图片

## English

[`cover.png`](cover.png) is the cover for **LZH's OMS Mods**, the seven-Mod collection for **Old Market Simulator**, displayed in the repository's main [README](../README.md).

The artwork was created with the built-in Image Gen tool for the Nexus Mods collection, using the existing Better Stacking cover as a style reference. This file preserves the original PNG unchanged (1672 × 941 pixels). It is generated promotional artwork, not an in-game screenshot. The original platform exports and generation prompt remain in the local media archive described in [Development](../DEVELOPMENT.md#media-archive--素材归档).

This image is for repository documentation and is not included in Mod packages.

## 中文

[`cover.png`](cover.png) 是 **Old Market Simulator** 七款 Mod 合集 **LZH's OMS Mods** 的封面，展示在仓库的[总 README](../README.md) 中。

图片最初使用内置 Image Gen 工具为 Nexus Mods 合集生成，以现有 Better Stacking 封面作为风格参考。此文件保留原始 PNG，未修改画面（1672 × 941 像素）。它是生成的宣传插画，并非游戏实机截图。原有平台导出文件与生成提示词继续保存在[开发说明](../DEVELOPMENT.md#media-archive--素材归档)所述的本地素材归档中。

此图片用于仓库文档，不包含在 Mod 安装包中。
