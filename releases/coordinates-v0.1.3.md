## English

Local player world coordinates beneath the money HUD, with an F8 toggle.

### Changes

Numbers follow the game/system format. Universal axis labels and native HUD styling are retained; the unused localization dependency has been removed. The packaged README is now English-first and Chinese-second, with versioned GitHub download links.

### Download and install

Requires BepInEx 5. X/Y/Z are universal axis labels; numbers follow the game/system culture and text follows native HUD styling.

Exit the game and back up the previous plugin. Extract the selected ZIP according to its README, preserving unrelated plugins and loader settings. Each plugin ZIP contains only the original DLL, README, and MIT LICENSE; no loader, game assembly, game asset, or save is bundled.

- `OldMarket.Coordinates-0.1.3.zip`
- `SHA256SUMS.txt`: SHA-256 checksums for the installation ZIPs above.

### Validation

Reference environment: Old Market Simulator 2.1.6, Windows x64 / Unity Mono.

Build and packaging checks passed. This mod has no translatable messages or localization-project dependency. Every mod was also built from a separate source directory without the other mods or a root localization project. Uploaded packages are checked against their recorded hashes.

**Prerelease: in-game acceptance is incomplete.** UI glyphs, wrapping, live language switching, save behavior, and multiplayer have not been validated solely by compilation or automated tests. Supplemental translations have not been reviewed by native speakers of every supported language.
